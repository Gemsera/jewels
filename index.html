    How placement works

    • Overview

    Every cluster jewel uses a fixed set of numbered slots: index 0–11 for Medium and Large, 0–5 for Small. Index 0 is always the entry, connected to the socket the jewel sits in. The game fills the slots in a fixed order: sockets first, then notables, then small passives. It then links the nodes in index order around a ring.

    Which notable takes which slot is decided by a hidden sort number for each notable in the game data. It is not the order printed on the item, and it is not alphabetical. The notable with the lowest number always takes the lowest free notable slot.

    The socket's location on the tree only rotates the jewel so the entry faces the parent socket. It never changes which slot a notable lands in or how many points it costs.

    Sockets

    • Large: socket list [4, 8, 6]. A rare Large has 2 sockets, at 4 and 8. A Large with exactly 1 socket always uses 6. Voices (3 sockets) uses 4, 8 and 6.
    • Medium: socket list [6], on the opposite side of the ring from the entry. Small jewels have no sockets.

    Notables

    • Notable slot lists: Large [6, 4, 8, 10, 2], Medium [6, 10, 2, 0], Small [4].
    • The game walks the list and skips slots already taken by sockets until it has one slot per notable. It then sorts those slots ascending and gives them out by sort number.
    • Medium special cases: a 4-passive Medium moves 10→9 and 2→3, putting its notables right next to the entry. A Medium with no socket and 2 notables moves 6→4 and 10→8.
    • Rare Large with 2 sockets and 3 notables → slots [2, 6, 10]: lowest sort number goes in front, the middle one at the back, the highest in front.
    • Large with 2 notables → slots [6, 10]: the lower sort number goes to the back.
    • Small passive slot lists: Large [0, 4, 6, 8, 10, 2, 7, 5, 9, 3, 11, 1], Medium [0, 6, 8, 4, 10, 2], Small [0, 4, 2]. Free slots fill in that order. 4- and 5-passive Medium jewels remap 8→9 and 4→3.
    • All nodes are linked in index order. Medium and Large jewels close the ring (last ↔ first), so you can path both ways from the entry. Small jewels are a straight chain.
    • The tree has 6 Large sockets on its outer ring, and each accepts Large, Medium or Small jewels. Sockets added by a Large accept Medium or Small. Sockets added by a Medium accept Small only.
    • Each socket has a hidden position proxy, an invisible group where the cluster is drawn, plus an orbit offset for each jewel size. A node's position is (index + offset) mod slots, which turns index 0 to face the parent socket.
    • Large jewels sit on orbit 3 (radius 335) and Medium on orbit 2 (radius 162). Both are 16-slot orbits since 3.17, so the 12-slot layout is spread onto them. Small jewels sit on orbit 1 (radius 82, 6 slots).
    • The ring and its links turn as one piece, so point costs inside a jewel are identical in every socket. Location only changes how far the socket is from your tree, which way the cluster faces, and where its child sockets appear.
    • Megalomaniac is a Medium cluster jewel with 4 passives, 0 sockets and 3 notables. Its small passive grants nothing. The notables can be any cluster notable, including Large-only ones, suffixes and a few that no longer roll on rare jewels.
    • The 4-passive Medium rule applies: [6, 10, 2, 0] → [6, 9, 3, 0]. The first three are taken and sorted → [3, 6, 9]. The “Nothing” passive takes index 0.
    • Lowest sort number → 3 (front, 2 pts), middle → 6 (back, 3 pts), highest → 9 (front, 2 pts). Both front notables together cost 3 points, and the whole jewel costs 4.
    • If you only want two of the three notables, the one you don't want needs the middle sort number.
    • An 8-passive Large with 3 notables puts 2 notables right next to the entry and 1 at the back. It's the most point-efficient Large.
    • If you only want one notable from a 2-notable Large, it must be the one with the higher sort number, which sits in front.
    • On a 4-passive Medium every notable is next to the entry: 2 points for 1 notable, 3 for both.
    • On a Small jewel the notable is always at the end of the chain: 2 points on a 2-passive Small, 3 on a 3-passive Small.

    The placement logic is ported from Path of Building Community (PassiveSpec:BuildSubgraph, getClusterJewelNotableIndices). Tree layout, socket proxies, orbit offsets, notable sort order and notable pools come from PoB's game data (tree 3.30). Every computed child-socket position matches its socket node on the real tree.
